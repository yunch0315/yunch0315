## 🎵 Featured Project — LINKBEAT

<div align="center">

### **[LINKBEAT — Auto-Chart Rhythm Game](https://github.com/yunch0315/linkbeat)**
*오디오 파일이나 링크만으로 음원을 실시간 분석해 채보를 자동 생성하는 크로스 플랫폼 리듬게임*

[![Release](https://img.shields.io/github/v/release/yunch0315/linkbeat?style=for-the-badge&color=3ef0ff&label=Release%20v1.0.5)](https://github.com/yunch0315/linkbeat/releases/latest)
[![Repo](https://img.shields.io/badge/GitHub-yunch0315%2Flinkbeat-181717?style=for-the-badge&logo=github)](https://github.com/yunch0315/linkbeat)
[![Platform](https://img.shields.io/badge/Platform-Web%20|%20macOS%20|%20Windows%20|%20Android-blueviolet?style=for-the-badge)](https://github.com/yunch0315/linkbeat)

**[📱 Android APK](https://github.com/yunch0315/linkbeat/releases/latest/download/LINKBEAT.apk)** · **[🍏 macOS DMG (Apple Silicon)](https://github.com/yunch0315/linkbeat/releases/latest/download/LINKBEAT-mac-arm64.dmg)** · **[🪟 Windows (LINKBEAT.exe)](https://github.com/yunch0315/linkbeat/releases/latest/download/LINKBEAT-win-x64-portable.zip)**

</div>

- **Audio DSP & Auto-Chart Algorithm**:
  - `STFT`(단시간 푸리에 변환) 및 `SuperFlux` 온셋 감지를 통한 정밀 어택 피크 검출
  - 2:1, 3:2 하모닉 배수 템포 후보 탐색 및 서브밀리초(Sub-ms) 전역 비트 격자 양자화
  - 3Key(Easy) / 5Key(Hard) / 7Key(Insane) 난이도별 지능형 채보 패턴(롱노트, 슬라이드, 16분 스트림) 생성
- **Zero-Latency Game Engine**:
  - `Web Audio API` (`getOutputTimestamp`) 기반 하드웨어 버퍼 출력 지연 실시간 보정 시계
  - `HTML5 Canvas 2D` 고성능 60~120fps+ 렌더링 & `Web Workers` 비동기 오디오 분석
- **Cross-Platform Engineering**:
  - 🍏 **macOS** / 🪟 **Windows**: Electron 44 데스크톱 앱 (로컬 격리 서버, QuickJS + yt-dlp 직접 재생)
  - 📱 **Android**: Kotlin 네이티브 앱 (Android SDK 35, `PRIMITIVE_CLICK` 네이티브 햅틱, `ExtractService` 백그라운드 추출 서비스 및 시스템 공유 시트 연동)
- 🔗 **GitHub Repository**: [yunch0315/linkbeat](https://github.com/yunch0315/linkbeat)
